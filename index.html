Leveling Client

Leveling Client is an independent launcher/client project for Minecraft: Java Edition, focused on user experience, customization and secure integration with official Microsoft authentication.

Independent Minecraft: Java Edition launcher/client project.

Official Microsoft Sign-In

Authentication is handled through Microsoft's official authentication infrastructure. Leveling does not create its own password fields or collect Microsoft account passwords.

Minecraft Java Edition

The launcher is designed to allow authenticated users who legitimately own Minecraft: Java Edition to access their account and the related Minecraft services.

Privacy & Security

  • Leveling does not ask users to enter their Microsoft password into an interface created by the launcher itself.
  • The authentication flow uses Microsoft's official sign-in experience, including consent and two-factor authentication when applicable.
  • Sensitive credentials such as Microsoft account passwords are not part of the launcher code and are not stored by the project.
  • Authentication tokens are used only to complete the Microsoft/Xbox/Minecraft authentication flow required for the user's login.
  • The desktop application does not use a Client Secret.

Purpose of Integration

The Microsoft/Xbox/Minecraft integration is used exclusively to authenticate the user, confirm access to the corresponding account, and allow the launcher to access the services required to start Minecraft in an authenticated state.
