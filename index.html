Leveling Client

O Leveling Client é um projeto independente de launcher/client para Minecraft: Java Edition, focado em experiência de usuário, personalização e integração segura com a autenticação oficial da Microsoft.

Login Microsoft oficial

A autenticação é realizada pela infraestrutura oficial da Microsoft. O Leveling não cria campos próprios para coletar a senha da conta Microsoft.

Minecraft Java Edition

O launcher foi projetado para permitir que usuários autenticados acessem sua conta legítima de Minecraft: Java Edition e os serviços relacionados.

Privacidade e segurança

  • O Leveling não solicita que o usuário digite sua senha Microsoft em uma interface criada pelo próprio launcher.
  • O fluxo de autenticação utiliza a experiência oficial da Microsoft para login, consentimento e verificação em duas etapas quando aplicável.
  • Credenciais sensíveis, como senha da conta Microsoft, não fazem parte do código do launcher e não são armazenadas pelo projeto.
  • Tokens de autenticação são usados somente para concluir o fluxo de acesso aos serviços Microsoft/Xbox/Minecraft necessários ao login do usuário.
  • O projeto não utiliza Client Secret no aplicativo desktop.

Finalidade da integração

A integração Microsoft/Xbox/Minecraft é usada exclusivamente para autenticar o usuário, confirmar o acesso à conta correspondente e permitir que o launcher acesse os serviços necessários para iniciar o Minecraft de forma autenticada.
